# 🍎🥦 Fruits & Vegetables AI – Smart Nutrition Advisor

This project combines **Computer Vision**, **ML Numeric Data**, and **NLP** to build a smart nutrition advisor.

## 🎯 Use Case
Upload a photo of a fruit or vegetable → the app identifies it, estimates nutritional values, and generates personalized recipe suggestions.

## 🔗 Blocks
- **CV:** CLIP Zero-Shot classifies the fruit/vegetable type
- **ML:** Random Forest predicts calorie content and nutritional values
- **NLP:** GPT-4o-mini generates recipe suggestions and health advice
